# 🍕Odin Recipe project

## Inttroduction
This project is part of **The Odin Project – Foundations Course**. It is my first project where I use **only HTML** to build a simple website that displays a collection of recipes. The main goal is to practice writing clean and well-structured HTML while learning how to organize content across multiple web pages.

The website includes a main index page that links to several individual recipe pages. Each recipe page contains a title, an image, a list of ingredients, and step-by-step instructions.

## 💡 Skills Demonstrated
By completing this project, I will have practiced and demonstrated the following skills:

- Writing valid and semantic **HTML** code  
- Structuring web pages with headings, paragraphs, lists, and images  
- Using **links** (`<a>`) to navigate between pages  
- Organizing files and folders for a small website project  
- Understanding the basic workflow of creating and viewing web pages locally
